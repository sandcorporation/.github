샌드코프는 웹·모바일 서비스를 **기획부터 설계·개발·배포·운영까지 한 번에** 맡습니다.
외주를 맡겨도 담당자가 바뀌지 않고, 만든 사람이 운영까지 책임집니다.

### 🚀 운영 중인 서비스

| | 서비스 | 소개 |
|---|---|---|
| 🏆 | [**Codemit**](https://codemit.kr) | 상금 공모전 플랫폼과 LLM 즉시 채점 코딩 강의실. 프로그래머스 데브코스 실수업에서 사용 중 |
| 📝 | [**Daypage**](https://daypage.sandcorp.co.kr) | 링크 하나로 함께 그리고 쓰는 하루 노트. 자정마다 새 페이지가 열리고 지난 페이지는 기록으로 |
| 📰 | [**AI Trend News**](https://news.sandcorp.co.kr) | AI·IT 뉴스를 AI 편집자가 골라 한국어로 요약 |

### 🤖 AI 에이전트가 함께 운영합니다

| 무엇을 | 어떻게 |
|---|---|
| **운영 오류 자동 수리** | 오류가 수집되면 에이전트가 재현 테스트부터 만들고 고쳐 PR을 올립니다. CI가 통과해 병합돼야 해결로 처리합니다. |
| **사용자 건의 자동 반영** | 건의가 들어오면 에이전트가 구현하고, 사람이 승인하면 배포와 공지까지 끝냅니다. |
| **콘텐츠 편집** | 수집한 뉴스를 에이전트가 묶고 요약해 게시합니다. |
| **MCP로 연결된 관리** | 서비스마다 MCP 서버를 두어 관리 작업을 AI 도구에서 바로 합니다. |

**문은 사람이 엽니다** — 재현되지 않은 수정은 내보내지 않고, 설계 결정은 사람에게 넘기며, 사용자 입력은 지시가 아닌 데이터로만 다룹니다.

### 🛠️ 이런 일을 합니다

- **웹 서비스** — Next.js · React, Django · Spring Boot, 결제 · 알림 · 관리자 페이지
- **모바일 앱** — React Native 크로스플랫폼, 네이티브 모듈, 스토어 출시 · 운영
- **AI 기능** — RAG 챗봇, LLM 채점 · 분류 자동화, MCP 서버
- **인프라 · 운영** — Docker · Kubernetes, Jenkins CI/CD, 모니터링, 무중단 배포, AI 운영 자동화
